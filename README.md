# Belagavi World Tourism Day Marathon 2026

Official web presentation deck and event dossier for the **Belagavi Marathon & World Tourism Day 2026** organized under the District Administration, Belagavi.

## 🚀 Live Demo & Deployment
- Ready for one-click hosting on **[Vercel](https://vercel.com/)**.
- Entry point: `index.html` (Interactive Presentation Deck with Live Route Map, Schedule, Cultural Showcase, and Registration Info).

---

## 📁 Repository Structure

```
├── index.html                  # Main interactive presentation deck (Vercel entry)
├── belagavi-marathon-2026.html # Presentation deck alias
├── belagavi-marathon-2026.pdf  # 11-Page HD Standalone Presentation Deck (16:9)
├── assets/                     # Optimized visual assets & landmark imagery
├── notes/                      # Original meeting notes & references
├── event.md                    # Detailed event plan & operational dossier
├── budget.md                   # District budget & sponsorship allocations
├── vercel.json                 # Vercel configuration
└── .gitignore                  # Git ignore rules
```

---

## 🏃 Highlights & Features
- **Official Route**: 8.8 km cultural corridor starting from Lele Ground to Kumar Gandharv Auditorium.
- **Cultural Showcase**: Karadi Majalu, Yakshagana, Dollu Kunitha, Dhol Tasha, and Belagavi Fort heritage landmarks.
- **Interactive Deck**: Built with vector route map, countdown timer, speaker profiles, and live schedule.
- **Vercel Optimized**: Zero build step required; instant static deployment.
